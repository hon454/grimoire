# token-weather

Claude Code 프롬프트 위 한 줄: 컨텍스트 토큰과 날씨, 최근 프롬프트별 막대, 5시간·7일 한도를 경과 시간과 비교한 게이지, 프롬프트 캐시의 남은 시간, 세션 비용, 실행 중인 에이전트.

```
☂ 634k ▃▄▂█▆ ▲ +6.3k │ 5h ━━━━╍─ 74% · 24 min │ 7d ━━━━── 65% · 2d20h │ cache 52 min │ ≈ $41.07 (+$0.58 · +1.5% 5h) │ 2 agents
```

Eric Cologni의 [token-weather-usage](https://github.com/augiefra/claude-mods)(Apache-2.0)를 그리모어 규약에 맞춰 옮긴 것입니다. 바뀐 점은 프랑스어·러시아어 대신 한국어 라벨, 한글처럼 폭이 2인 글자를 고려한 터미널 폭 계산, 그리모어의 디렉토리와 이름입니다. 출처와 adapt한 코드의 고지는 [NOTICE](NOTICE)에 있습니다.

Claude Code 전용 mod입니다. Codex에는 설치되지 않으며 Codex 마켓플레이스에도 실리지 않습니다.

## 블록

- **컨텍스트**: 토큰 수와 날씨 아이콘(25/50/75/90%에서 ☀ ☁ ☂ ☇ ↯), 최근 프롬프트 5개가 더한 토큰 막대, 마지막 프롬프트의 증감. 앱에서는 알약 위에 마우스를 올리면 날씨와 창 대비 비율이 보입니다.
- **5시간 / 7일**: 계정 한도의 사용 비율. 경과 시간보다 빠르게 쓰면 노랑, 15포인트 이상 앞서거나 90% 이상이면 빨강. 경과 시간과의 차이는 빗금. 그다음 남은 시간. 주간 속도로 7일 한도가 초기화 전에 소진될 때는 `⚠ 일요일 저녁 소진` 같은 경고가 붙습니다(주 첫날 이후, 15% 이상 사용 시, 터미널이 좁으면 숨김).
- **캐시**: 프롬프트 캐시가 만료되기까지의 시간(구독 1시간, API 키 5분, 트래픽에서 추론). 마지막 메시지가 캐시에서 읽은 비율은 90% 미만일 때만 표시. 10분 미만이면 노랑과 함께 만료 시 비용, "미스"는 원인과 추가 비용, "만료"는 빨강과 함께 다시 쓰는 비용과 `/compact`(100k 이상) 또는 새 스레드(300k 이상) 권고. 달러는 Anthropic 정가(2026-10-08 기준)이며 구독에서는 API 가격 환산치라 `≈`가 붙습니다. 가격표에 없는 모델은 토큰만 보여 줍니다.
- **비용**: `/cost`가 합산하는 세션 비용과 마지막 프롬프트가 더한 금액(달러와 5시간 한도 포인트).
- **에이전트**: 이 스레드가 실행한 서브에이전트 수. 앱에서는 알약 위에서 모델·effort별 비용 분해, 실행 중인 에이전트의 최근 도구 이름(인자는 절대 아님), 마지막 묶음의 소요 시간·병렬도·도구 호출 수·비용, 위임으로 아낀 비용을 보여 줍니다.

라벨은 영어 또는 한국어입니다. `auto`는 `LC_ALL`, `LC_MESSAGES`, `LANG`을 따르고, 데스크톱 앱처럼 이 변수가 없는 환경에서는 `/config`의 **Language** 옵션에서 `en`이나 `ko`를 고릅니다.

## 개인정보

네트워크 요청 없음, 파일 읽기 없음, 도구 호출 가로채기 없음. Claude Code가 제공하는 사용량 수치, 세션의 서브에이전트 목록과 응답이 요청한 도구 이름, 로케일 변수와 프롬프트 캐시 스위치만 읽습니다. 플러그인 저장소에는 최신 한도 수치, 최근 이틀의 7일 사용률(30분당 하나), 세션별 컨텍스트 기록·캐시 상태·절약액·에이전트 요약(8일 유휴 후 삭제)을 둡니다.

모든 훅은 읽기만 하고 이벤트를 그대로 넘깁니다(`return next(e)`). 아무것도 바꾸거나 지연시키거나 거부하지 않습니다.
